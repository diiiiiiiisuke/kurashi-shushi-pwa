# スマホから開発・管理する方法

## 基本の流れ

1. **やりたいことを書く** — GitHubアプリ（またはブラウザ）で Issue を作るか、`docs/roadmap.md` に追記する
2. **AIに頼む** — ChatGPTアプリのCodex（またはClaudeアプリのClaude Code）でこのリポジトリを選び、「`AGENTS.md` を読んで、roadmap の◯◯を実装して」のように依頼する
3. **確認する** — エージェントが作ったブランチ／プルリクエストをGitHubアプリで確認。CI（check）が緑か見る
4. **反映する** — 問題なければ `main` にマージ。数分で Cloudflare Pages に反映される（マージ前に、プルリクエストに付くプレビュー用URLで試すこともできる）
5. **スマホで開き直す** — ホーム画面のアプリを開き直す（オンラインなら最新版が読み込まれる）。反映されないときは、アプリを完全に終了してからもう一度開く

## AIへの依頼文のひな形

```
AGENTS.md と docs/ を読んでから作業してください。
やりたいこと: （例）予算を編集できるようにしたい
終わったら scripts/check.sh を通し、docs/worklog.md と docs/roadmap.md を更新してください。
```

## ちょっとした修正を自分でする

- GitHubアプリやブラウザでファイルを開き、鉛筆アイコンで直接編集してコミットできる
- 文言や色の変更くらいならこれで十分。`app.js` などを変えたら `sw.js` の `CACHE` の番号も上げる
- ブラウザ版GitHubでリポジトリを開いた状態で `.` キー（PCのみ）を押すと、github.dev のエディタが開く

## Codex に頼んでから、スマホのアプリが新しくなるまで

```
スマホで Codex に依頼 → Codex がブランチを作り、プルリクエストを出す
→ CI（check）が自動で動く → 緑ならオーナーが「マージ」を1タップ
→ Cloudflare Pages が1〜2分で自動公開 → ホーム画面のアプリを開き直すと新しい版
```

- 最初に1回だけ: ChatGPT の Codex の設定で GitHub を接続し、このリポジトリを選ぶ。Codex は `AGENTS.md` を自動で読む
- マージは人が1タップで行う（`docs/security.md`: AIの変更を確認してから入れる）。CIが緑になったら自動でマージする設定（GitHub の auto-merge）にもできるが、その場合は「金額が外部に送られる変更」なども確認なしで公開されるため、今は使っていない
- データ形式を変える変更でも、`migrate()` で今のデータは自動で引き継がれる（`AGENTS.md` のルール）

## iPhone で使うときの注意

- **ホーム画面のアプリと Safari のタブは、データの保存場所が別**。ホーム画面に追加したら、記録・読み込みは必ずホーム画面のアプリから行う（Safari で入れたデータはアプリには出ない）
- ホーム画面のアプリを削除すると、中のデータも消える。消す前に必ず「設定 → 書き出す」
- 一度開けば、圏外でも入力・閲覧できる（更新の確認はオンラインのときだけ）

## アプリの使い方（データの扱い）

- 公開URL: `docs/deploy.md` を参照（Cloudflare Pages）
- iPhone: Safariで開く → 共有 → 「ホーム画面に追加」
- Android: Chromeで開く → 「アプリを追加」ボタン、またはメニュー → 「ホーム画面に追加」
- 記録は端末内だけに保存される。機種変更・ブラウザのデータ削除の前に「設定 → データを書き出す」でバックアップする
- **バックアップファイルはGitHubに上げない**（リポジトリは公開）
