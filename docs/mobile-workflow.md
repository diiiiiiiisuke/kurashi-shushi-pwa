# スマホから開発・管理する方法

## 基本の流れ

1. **やりたいことを書く** — GitHubアプリ（またはブラウザ）で Issue を作るか、`docs/roadmap.md` に追記する
2. **AIに頼む** — ChatGPTアプリのCodex（またはClaudeアプリのClaude Code）でこのリポジトリを選び、「`AGENTS.md` を読んで、roadmap の◯◯を実装して」のように依頼する
3. **確認する** — エージェントが作ったブランチ／プルリクエストをGitHubアプリで確認。CI（check）が緑か見る
4. **反映する** — 問題なければ `main` にマージ。数分でGitHub Pagesに反映される
5. **スマホで開き直す** — ホーム画面のアプリを開き直す（オンラインなら最新版が読み込まれる）

## AIへの依頼文のひな形

```
AGENTS.md と docs/ を読んでから作業してください。
やりたいこと: （例）予算を編集できるようにしたい
終わったら scripts/check.sh を通し、docs/worklog.md と docs/roadmap.md を更新してください。
```

## ちょっとした修正を自分でする

- GitHubアプリやブラウザでファイルを開き、鉛筆アイコンで直接編集してコミットできる
- 文言や色の変更くらいならこれで十分。`app.js` などを変えたら `sw.js` の `CACHE` の番号も上げる
- ブラウザ版GitHubでリポジトリを開いた状態で `.` キー（PCのみ）を押すと、github.dev のエディタが開く

## アプリの使い方（データの扱い）

- 公開URL: https://diiiiiiiisuke.github.io/kurashi-shushi-pwa/
- iPhone: Safariで開く → 共有 → 「ホーム画面に追加」
- Android: Chromeで開く → 「アプリを追加」ボタン、またはメニュー → 「ホーム画面に追加」
- 記録は端末内だけに保存される。機種変更・ブラウザのデータ削除の前に「設定 → データを書き出す」でバックアップする
- **バックアップファイルはGitHubに上げない**（リポジトリは公開）
