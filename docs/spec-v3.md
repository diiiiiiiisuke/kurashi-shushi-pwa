# 指示書: くらし収支 v3（Notion風DB・カード別の可視化・返済スピードのグラフ）

- 作成: 2026-10-12（Claude Code）
- 状態: 実装済み（2026-10-12）
- 前提: [spec-v2.md](spec-v2.md) と `AGENTS.md` のルール（依存なし・ビルドなし・CSPを緩めない）

## 1. オーナーの依頼

1. **Notion のデータベースのような見た目**で記録を管理したい
2. **マネーフォワードのように、クレジットカード別に「何にいくら使ったか」**を見たい
3. **毎日の家計簿・月次の管理などを、プルダウンで切り替え**たい
4. **どのくらいのスピードで返済すれば、いつ完済できるか**を棒グラフ・折れ線グラフで見たい。**未来（予測）の部分は点線**

## 2. 記録タブ → 「家計簿DB」

Notion のデータベースのように、1つのデータ（記録）を **ビュー** を切り替えて見る。

### 2.1 ビューの切り替え（プルダウン）

タイトル「家計簿DB」の下にプルダウンを置く。選んだビューは `settings.recordsView` に保存し、次に開いたときも同じビューにする。

| 値 | 表示名 | 内容 | 月の切り替え |
| --- | --- | --- | --- |
| `daily` | 📅 毎日の家計簿 | 日付ごとにグループ化した表。グループ見出しに件数と1日の収支 | 使う |
| `monthly` | 🗓 月次の管理 | 1行＝1か月の表（12か月）。収入・支出・収支・貯蓄率・予算の消化・支出の多いカテゴリ。行をタップすると、その月の「毎日の家計簿」へ | 表示月までの12か月 |
| `card` | 💳 カード別 | 支払方法ごとにグループ化。グループ見出しにカテゴリ別の積み上げ棒（何にいくら使ったか）と合計 | 使う |
| `category` | 🏷 カテゴリ別 | カテゴリごとにグループ化。予算があれば消化率 | 使う |
| `table` | 📋 テーブル | グループなしの表。並び替え（日付・金額）ができる | 使う |

検索・カテゴリ・区分の絞り込みは `monthly` 以外のビューで共通に使う。

### 2.2 Notion風の表

- 列（プロパティ）: `Aa 内容` / `📅 日付` / `🏷 カテゴリ` / `💳 支払方法` / `# 金額` / `区分`
- カテゴリ・支払方法は **色付きのタグ**（Notion のタグと同じ9色: gray, brown, orange, yellow, green, blue, purple, pink, red）。色は名前から自動で決める（同じ名前は常に同じ色）
- 行をタップすると編集シートが開く。表の最後に「＋ 新規」行
- スマホでは表を横スクロールし、`内容` 列は左に固定する
- グループ見出し: `▾ グループ名  件数  合計`

## 3. カード別の可視化（マネーフォワード風）

- 「カード別」ビューと、分析タブの「支払方法別の支出」で同じ部品を使う
- 支払方法ごとに: 名前・その月の支出合計・全体に占める割合・**カテゴリ別の積み上げ横棒**・上位カテゴリの金額
- 計算は `js/calc/summary.js` の `byAccount(txs)`（支出のみ。支出の多い順）

## 4. 返済のグラフ

### 4.1 残債の推移（実績＋予測）

- X軸: 月。過去（実績）→ 今 → 未来（予測）
- **折れ線＝残債**: 実績は実線、予測は **点線**。「今」に縦線を引き、未来側の背景を薄く塗る
- **棒＝その月の返済額**: 実績は濃い色、予測は薄い色＋点線の枠
- 予測は「返済スピード」ごとに複数の点線を重ねる（最低返済額だけ／設定した毎月の額／＋1万円／＋3万円）。設定した額の線を太くし、棒はその額のもの
- 実績の残債（月末時点）は、各返済先の基準残高と返済記録の元金から逆算する（`balanceAt`）
  - 基準日以降: `基準残高 − (基準日〜その日の元金の合計)`
  - 基準日より前: `基準残高 + (その日の翌日〜基準日前日の元金の合計)`
- 実績の期間: 最初の返済記録の月または基準日の月から、最大12か月前まで
- 予測の期間: 表示しているスピードのうち最も遅い完済まで（最大10年）
- 返済先の詳細画面にも、その返済先だけの同じグラフを出す

### 4.2 返済スピードの比較

- 「毎月いくら返すと、何か月で完済し、利息がいくらか」を比べるグラフ
- **棒＝完済までの月数**、**折れ線（点線）＝利息の合計**。今の設定額の棒を強調する
- 毎月の額: 最低返済額の合計から、その3倍（または設定額の1.5倍の大きい方）まで6段階（1,000円単位で切り上げ）
- 下に同じ内容の表（毎月の額・完済・期間・利息・最低返済だけの場合との差）

計算は `js/calc/projection.js`（純粋関数、`tests/projection.test.mjs`）。
