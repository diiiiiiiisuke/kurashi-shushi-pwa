# 要件

## オーナーがやりたいこと（2026-10-12 時点）

1. **毎日の家計簿をつける** — 日々の支出・収入をスマホからすぐ入力し、日ごと・月ごとに見返す
2. **自分の収支状況を管理する** — 月の収入・支出・収支、予算の消化、事業の売上と経費、カード・ローンの返済状況をひと目で把握する
3. **PWAで使う** — スマホのホーム画面に追加してアプリのように使う。オフラインでも入力できる
4. **GitHubで管理する** — コード・仕様・作業記録をすべてGitHubに残し、スマホからも開発できるようにする。普段の開発はCodex

## 機能要件

詳細な仕様は [spec-v2.md](spec-v2.md)。以下は概要。

### 家計簿（収支）
- 収支の入力: 日付・収入/支出・個人/事業・カテゴリ・支払方法（現金・口座／登録カード）・金額・内容
- 収支の編集・削除
- 月ごとの一覧を、日付ごとにまとめて1日の収支つきで表示する
- カテゴリはよく使うものを候補に出す（自由入力も可）

### 収支状況
- 月の収入・支出・収支・登録残債の合計
- カテゴリ別予算と消化率（超過は赤）
- 支出のカテゴリ別グラフ
- 事業の売上・経費・概算利益

### 返済
- 返済先（カード・ローン・分割など）の残高、毎月の返済額、支払日、年利
- 支払予定の一覧
- 返済シミュレーション（毎月の返済総額と想定年利から完済時期を概算）

### 設定
- 支払カードの登録（締日・支払日）
- バックアップの書き出し・読み込み（JSON）

## 非機能要件
- データは端末内のみに保存し、外部に送信しない
- 依存ライブラリなし・ビルドなし（スマホからGitHub上で直接編集できるようにするため）
- 日本語UI、日本円、日本時間の日付
