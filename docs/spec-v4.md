# 指示書: くらし収支 v4（保有クレカの登録・管理／収支と返済を1つのグラフで）

- 作成: 2026-10-12（Claude Code）
- 状態: 実装済み（2026-10-12）
- 前提: [spec-v2.md](spec-v2.md)・[spec-v3.md](spec-v3.md)・`AGENTS.md`

## 1. オーナーの依頼

1. Notion の「保有クレカ」DBの「名前」列のカードを、すべて決済手段（支払方法）として追加したい
2. クレカの決済手段を増やしたり減らしたりできるようにしたい
3. 収支状況と返済状況をセットで見たい。**収支＝棒グラフ、残りの残債＝折れ線グラフ**

## 2. 保有クレカの登録

### 2.1 方針（なぜアプリに直接書き込まないか）

- このリポジトリは公開。カード名をコードや初期データに書くと「どのカードを持っているか」が公開される（`docs/security.md`）
- アプリのデータはスマホの中だけにあり、開発側から書き込めない
- → **「まとめて追加」機能**を作り、オーナーが Notion の「名前」列をコピーして貼り付ける。カード名はスマホの中だけに保存される

### 2.2 まとめて追加（設定 → 支払方法 → 📋 まとめて追加）

- 複数行のテキスト欄に貼り付ける。1行＝1件。タブ・カンマ区切りでも分ける（Notion の列をコピーすると改行区切り、表ごとコピーするとタブ区切りになるため、**各行の最初の項目**を名前として使う）
- 無視するもの: 空行、見出しの「名前」「Name」、行頭の「・」「-」「*」「1.」などの記号、前後の空白
- 同じ名前（すでに登録済み／貼り付けた中での重複）は追加しない
- 種類（カード／口座／現金）を選べる。初期値はカード
- 入力中に「追加される ◯件／すでにある ◯件」をプレビューする
- 計算は `js/calc/accounts.js` の `parseAccountNames(text, existingNames)`（テストあり）

### 2.3 増やす・減らす

- 増やす: 「＋ 追加」（1件ずつ）、「📋 まとめて追加」
- 減らす（編集シート）:
  - 一度も使っていない（記録・定期取引で未使用）→ **削除**できる
  - 使っている → **使わない（非表示）**。過去の記録は残り、入力の選択肢から消える。いつでも「使用を再開」できる
  - 「現金・口座」は削除・非表示にできない
- 一覧にはカードごとの「今月の利用額・件数」を表示する
- 並び順: 一覧の ↑↓ で入れ替える（入力シートの選択肢も同じ順）

## 3. 収支と返済（返済タブへ集約、2026-10-12更新）

- 1つのグラフに **棒＝毎月の収支**、**折れ線＝残りの残債** を重ねる。左の目盛りが収支、右の目盛りが残債
- 棒の表示はプルダウンで切り替え: 「収入と支出」（2本並び）／「収支（黒字・赤字）」（1本、黒字は緑・赤字は赤）
- 期間はプルダウンで切り替え: 「1年（前後6か月）」／「2年（前後12か月）」／「完済まで」（過去12か月〜完済月、最大10年）
- 残債の線: 過去は返済記録から逆算した月末残高（実線）、今月以降は設定した毎月の返済額での予測（点線）。未来の部分は背景を薄く塗る
- グラフの下に: 今月の収支／残債／完済予定／今月の返済額
- 選んだ表示・期間は `settings.overviewBars`・`settings.overviewRange` に保存
- 計算は `js/calc/projection.js` の `buildOverview()`（テストあり）

## 4. ホーム簡素化とカード別支払い予定（2026-10-12）

- オーナー依頼: 返済関連の表示を返済タブへ集約。ホームは収支サマリ・予算・最近の記録に絞る
- 分析からも返済専用グラフと利息のサマリを外し、返済タブに集約
- 次の支払い予定はカードごとに日付、カンマ区切りの金額、横棒を表示。個々の定期支出はカードの請求合計にまとめる
- 計算の前提・除外項目は architecture.md の「次回カード引き落としの計算」を参照。締日の翌月払いを標準とし、実際の明細とは差が生じることを表示
